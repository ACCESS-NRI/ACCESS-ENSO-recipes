# Ocean and sea-ice evaluation

| Folder | Data and method |
| --- | --- |
| [`cosima/`](cosima/) | Native ACCESS-OM/CICE fields and the COSIMA analysis approach |
| [`cmip6/`](cmip6/) | CMORised ocean and sea-ice fields processed with ESMValCore; [read the input and numerical limitations](cmip6/README.md) |
| [`russell2018/`](russell2018/) | Southern Ocean diagnostics following Russell et al. (2018) |

The CMIP6 notebooks are peers of the native-model notebooks because they use different input conventions and may not produce numerically identical results.
